Term Record

primary_transcript

SO:0000185

sequence

A transcript that in its initial state requires modification to be functional.

Definition xrefs: SO:ma

Comments

See "precursor_RNA" (SO:0002393) for RNA which may be the result of post-transcriptional processing. If the RNA in question is known not to have been processed, use this class ("primary_transcript"). On 9 Sep 2025, Removed "has_exact_synonym : INSDC_feature:precursor_RNA" and "has_exact_synonym : precursor RNA" from the annotation for this class at the request of Terence Murphy of NCBI. See GitHub Issue #655.
