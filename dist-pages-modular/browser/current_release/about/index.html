About this prototype

This prototype demonstrates the target URL contract and information architecture for a modernized Sequence Ontology website.

  • Displayed term annotations are sourced from the OWL release.
  • Graph structure is derived from the JSON graph export.
  • Each term has its own canonical URL.
  • The DAG acts as a navigational supplement, not the only way to understand relationships.

This prototype prioritizes direct term URLs, accessible text content, and clickable ontology navigation.
